# Pitch video — Meridian AI Platform

`Meridian_AI_Platform_Pitch.mp4`: a 4-minute narrated video (1080p) for managers and funding conversations. It has 11 slides.

1. Title · 2. Problem · 3. Solution · 4. Nine agents + Critic · 5. Trust safeguards · 6. Benchmark results ·
7. Enterprise readiness · 8. No LLM lock-in · 9. Business case · 10. Status & next steps · 11. The ask (pilot)

All figures come from the repo. Benchmark numbers are from `benchmark/results/results_20260607T152042Z.md`. Business-case numbers are estimates from `docs/product/phase1_strategy/01_business_case.md`, and the slides label them as estimates.

To edit, change `deck.html` (slides) or `narration.json` (voiceover script, one entry per slide), then run `./build.sh`.
The voice is Kokoro TTS (`am_michael`), which runs offline.
